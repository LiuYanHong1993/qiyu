# 契语（Qiyu）— 面向 AI 编程的可验证安全语言

> 工作名「契语」：契，取"合同、凭证"之意——语言是普通人意图与 AI 实现之间的合同。
> 一句话定位：**给企业里用 AI 做数据自动化的分析师，提供一种 Agent 可以生成、IT 敢于批准、业务可以托管的编程语言。**

## 🚀 独立编译器（v1.7.1）

`dist/qiyu.exe`（7.8MB，单文件，内嵌自有运行时——**运行 .qy 程序不再需要 Python**）：

```powershell
dist\qiyu.exe run  examples\销售日报.qy --根 fixtures\T01 --参数 日期=2024-06-01
dist\qiyu.exe check examples\每周销售周报.qy        # 输出审计包（审批用）
dist\qiyu.exe run  examples\每周销售周报.qy --试运行  # 外发只预报不执行
```
重新构建：`python -m PyInstaller --onefile --name qiyu --distpath dist --workpath build src/qiyu.py`

当前阶段：**阶段 0-1 完成 · 真模型实验四轮迭代完成（few-shot 后与 Python 一次通过率实质打平）**
