# T03 · 库存预警

- 难度：L1 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV
- 场景：仓库每周按库存表生成补货建议清单。

## 标准化提示词（两组通用）

> 读取 `inventory.csv`，输出 `replenish.csv`：仅包含 `现库存 < 安全库存` 的行（等于不算），字段 `SKU,名称,现库存,安全库存,缺口`，缺口 = 安全库存 − 现库存，按缺口降序、同缺口按 SKU 升序。

## 输入

```csv
SKU,名称,现库存,安全库存
A-001,六角螺母,40,50
A-002,平垫圈,80,80
```

## 输出

```csv
SKU,名称,现库存,安全库存,缺口
A-001,六角螺母,40,50,10
```

## 验收契约（自动断言）

1. 只含 现库存 < 安全库存 的行（边界行 A-002 不得出现）
2. 排序正确；缺口为非负整数且等于差值
3. 无多余行、无遗漏行
4. 未触发能力清单外访问

## Python 基线备注

LLM 常见错误：边界条件写成 ≤、排序键写反。

## 设计反哺

过滤 + 派生列 + 排序是"表格三件套"，应是契语核心算子。
