# T15 · KPI 看板数据

- 难度：L3 ｜ 能力：`fs.read` × 3、`fs.write` ｜ 数据形态：CSV × 3 → JSON
- 场景：运营月度把目标/实际/回款三张表合成看板 JSON。

## 标准化提示词（两组通用）

> 读 `targets.csv`（`月份,目标额`，单位**万元**）、`actuals.csv`（`月份,实际额`，单位**元**）、`payments.csv`（`月份,回款额`，单位**元**）；输出 `kpi.json`：`{"月份":[{"月份","目标额_元","实际额_元","完成率","回款率"}]}`；完成率 = 实际 ÷ 目标（目标为 0 或缺失 → null），保留 4 位小数；回款率同理；月份升序，数据缺失的月份也补全（目标缺失 → `目标额_元` = null）。

## 验收契约（自动断言）

1. 单位换算正确（万元 × 10000）← 本任务最大坑
2. null 语义正确：目标=0 与 目标缺失 是两种不同的触发，构造两种样例
3. JSON schema 校验通过
4. 缺月补全、升序

## Python 基线备注

LLM 常见错误：单位不换算、null 与 0 混淆、缺月遗漏。

## 设计反哺

**单位应是类型**（万元/元不可隐式混算）——静态可查、"错误即 prompt"的典型用例。
