# T08 · 汇率换算报表

- 难度：L3 ｜ 能力：`fs.read`、`fs.write`、`net.fetch`（仅 api.ex.com/rate） ｜ 数据形态：CSV + JSON API
- 场景：外贸团队的美元报价单每周按汇率换算成人民币版。

## 标准化提示词（两组通用）

> 读 `quotes_usd.csv`；通过 `GET https://api.ex.com/rate?from=USD&to=CNY` 获取汇率（返回 `{"rate":7.21,"date":"2024-06-07"}`）；同一日期内只请求一次，缓存到 `~/缓存/rate.json`（含 date 字段，先读缓存）；输出 `quotes_cny.csv`，金额 = 原金额 × rate，四舍五入到分。

## 输入

mock API 固定返回 rate=7.21。

## 验收契约（自动断言）

1. 金额数值正确（容差 < 0.005）
2. **API 调用次数 = 1**（mock 计数器断言）← 缓存/幂等考察点
3. 缓存文件存在且含日期字段
4. 舍入口径统一（四舍五入到分）

## Python 基线备注

LLM 常见错误：在行循环里重复请求 API、浮点误差累积、缓存读写逻辑缺失。

## 设计反哺

缓存与幂等应内建（如 `记忆 变量` 声明），模型不该手写缓存逻辑。
