# T12 · 批量报价单

- 难度：L2 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：模板 + CSV
- 场景：销售给一批客户逐个出报价单，手工改模板容易漏改日期。

## 标准化提示词（两组通用）

> 读 `clients.csv`（`客户名,金额`）与模板 `报价模板.md`（占位符 `{{客户名}} {{金额}} {{有效期}}`）；为每个客户生成 `~/报价单/{客户名}-报价单.md`；有效期 = 参数 `issue_date` + 30 天，格式 `YYYY年M月D日`；客户名中的 `/ \ : * ? " < > |` 字符替换为 `_`。

## 输入

构造数据含：跨月日期样例（6/18 → 7/18）、特殊字符客户名（`A/B公司`）。

## 验收契约（自动断言）

1. 每客户恰一文件；占位符零残留（全文无 `{{`）
2. 日期计算正确（跨月样例）
3. 特殊字符文件名被净化
4. 除报价单目录外无其他写操作

## Python 基线备注

LLM 常见错误：日期加天错误、忘处理非法文件名字符、占位符残留。

## 设计反哺

模板填充（`套模板 模板 数据`）应是内建算子；文件名净化规则属标准库。
