# T18 · 异常波动日报

- 难度：L3 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV
- 场景：销售运营每周看哪些区域波动异常，现在靠肉眼扫表。

## 标准化提示词（两组通用）

> 读 `sales_weekly.csv`（`周,区域,金额`，共 8 周），以参数 `current_week`；对每区域：变化率 = (本周 − 上周) ÷ 上周；异常 = |变化率| > 0.5 且 本周金额 > 10000；上周 = 0 且 本周 > 0 → 记 `新增`（不参与变化率排序，排在最后）；输出 `anomaly.csv`：`区域,上周,本周,变化率,类型[暴涨/暴跌/新增]`（暴涨 = 变化率 > 0.5，暴跌 = < −0.5），按|变化率|降序、新增垫底；另生成 `summary.txt` 一行结论（异常区域数与最大波动）。

## 输入

构造数据：恰好 0.5（不算异常）、上周=0、暴跌样例、上周=0 且本周=0。

## 验收契约（自动断言）

1. 与构造答案集完全一致（零漏报零误报）
2. 口径 = (本周−上周)/上周；恰好 0.5 不算异常
3. 排序正确（新增垫底）
4. summary 内容与数据一致

## Python 基线备注

LLM 常见错误：除零崩溃、边界 0.5 方向、绝对值比较写错。

## 设计反哺

统计口径（分母、边界、方向）必须可显式声明，否则模型各自发挥。
