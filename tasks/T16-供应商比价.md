# T16 · 供应商比价

- 难度：L2 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV × 4
- 场景：采购把三家供应商报价表对比选优，规则常年靠脑子记。

## 标准化提示词（两组通用）

> 读 `supplier_a.csv / supplier_b.csv / supplier_c.csv`（`SKU,报价,起订量,交期天`）与 `needs.csv`（`SKU,需求量`）；每个 SKU：候选 = 起订量 ≤ 需求量 且 交期 ≤ 7 天 的供应商；在候选中取报价最低者为建议供应商；无候选 → 状态=`需人工`；报价平局 → 取供应商名字母序第一。输出 `advice.csv`：`SKU,建议供应商,报价,状态[已选/需人工]`。

## 验收契约（自动断言）

1. 选择符合规则（构造：被起订量卡掉的候选、交期超 7 天的候选、平价对）
2. 平局确定性（按字母序）
3. 无候选行状态正确且建议供应商为空
4. 全 SKU 覆盖

## Python 基线备注

LLM 常见错误：过滤条件漏一条、平局处理依赖遍历顺序（输出不确定）。

## 设计反哺

决策规则应可写成显式规则块（规则即数据），禁止模型自由发挥。
