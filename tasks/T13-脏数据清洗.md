# T13 · 脏数据清洗

- 难度：L1 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV
- 场景：从各处收上来的表格永远脏：日期三种格式、金额带符号、重复行。

## 标准化提示词（两组通用）

> 清洗 `dirty.csv` → `clean.csv` + `report.csv`。规则：① 金额去 `¥` 与千分位逗号转数字（`¥1,234.50` → 1234.50）；② 日期支持 `2024/6/1`、`2024-06-01`、`20240601`，统一为 `YYYY-MM-DD`；③ 字符串去首尾空格；④ 完全重复行去重（保留首次出现）。`report.csv` 每行：`列名,操作,数量`（操作 ∈ 格式修正/去空格/去重；空值原样保留）。

## 验收契约（自动断言）

1. clean.csv 无空格残留；日期金额格式统一且与规则重算一致
2. 重复行仅保留首条
3. report.csv 计数 = 实际操作数（逐项核对）
4. 空值保留、不填充

## Python 基线备注

LLM 常见错误：日期解析顺序（20240601 先被当成数字）、金额正则漏掉全角符号、去重键定义模糊。

## 设计反哺

显式规则清单 → 契语可让"清洗管道"可声明、可校验、可复用。
