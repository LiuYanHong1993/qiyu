# T07 · 客户跟进提醒

- 难度：L3 ｜ 能力：`fs.read`、`fs.write`、`im.send`（企业微信 webhook，mock） ｜ 数据形态：CSV + IM
- 场景：销售助理每周筛出超过 14 天没跟进的客户，推送到团队群。

## 标准化提示词（两组通用）

> 读 `customers.csv`（含 `最后跟进日期`），以参数 `today` 为"今天"；筛选距今超过 14 天的行输出 `followup.csv`（原字段 + `超期天数`），按超期天数降序；每行推送一条企业微信消息（mock），内容含客户名与超期天数。

## 输入

构造数据含：恰好 14 天（不算超期）、15 天、跨月样例。

## 验收契约（自动断言）

1. 清单 = 超期集合（恰好 14 天的边界行不得出现）
2. 消息条数 = 清单行数，内容含客户名与天数
3. **today 只能来自参数**：mock 时钟注入检测，任何系统时间调用判失败 ← 复现性原则
4. 未触发能力清单外访问

## Python 基线备注

LLM 常见错误：`datetime.now()` 导致不可复现、边界 ≥/≤ 写错、日期差单位算错。

## 设计反哺

"当前时间"是隐式环境权限——契语必须显式传入或声明时间来源，保证审计可回放。
