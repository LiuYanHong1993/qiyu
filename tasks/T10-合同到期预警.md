# T10 · 合同到期预警

- 难度：L3 ｜ 能力：`fs.read`、`fs.write`、`mail.send`（仅 legal@company.com） ｜ 数据形态：CSV + 邮件
- 场景：法务助理每周核对台账，提前 30 天提醒续签。

## 标准化提示词（两组通用）

> 读 `contracts.csv`（含 `签约日,期限,单位[月/年]`），以参数 `today` 为参照；到期日 = 签约日 + 期限；输出 `expiring.csv`：满足 `today ≤ 到期日 ≤ today+30天` 的合同（原字段 + `到期日,剩余天数`），按剩余天数升序；再汇总一封邮件给 legal@company.com（主题 `合同到期预警`，正文列出合同数）。

## 输入

构造数据含：单位=年、跨年进位、恰好 30 天边界。

## 验收契约（自动断言）

1. 日期运算正确（年→12 月；跨年样例）
2. 边界规则 ≤ 30 天（恰好 30 天的必须包含）
3. 邮件恰 1 封、收件人精确、正文含合同数
4. today 仅来自参数（mock 时钟检测）

## Python 基线备注

LLM 常见错误：月/年单位混算、`timedelta(days=30)` 边界、邮件正文漏合同数。

## 设计反哺

日期/时长算术应强类型进标准库（"1 个月 ≠ 30 天"的语义要显式）。
