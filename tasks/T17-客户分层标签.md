# T17 · 客户分层标签

- 难度：L2 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV
- 场景：销售运营按消费给客户打标签，规则有优先级。

## 标准化提示词（两组通用）

> 读 `customers.csv`（`客户,年度消费,最近消费日`），以参数 `today`；标签按序判定：① 距最近消费 > 365 天 → `沉睡`；② 年度消费 ≥ 100000 → `VIP`；③ ≥ 10000 → `重要`；④ 其他 → `普通`。输出 `customers_tagged.csv`（原字段 + `标签`）与 `segments.csv`（`标签,客户数`）。

## 输入

构造边界数据：12 万但沉睡（→沉睡）、恰好 365 天、恰好 366 天、恰好 10 万、恰好 1 万。

## 验收契约（自动断言）

1. 每客户恰一标签；优先级正确（12 万 + 沉睡 → 沉睡）
2. 边界含等号正确（恰好 10 万 → VIP；恰好 1 万 → 重要）
3. segments 计数与明细一致
4. today 仅来自参数

## Python 基线备注

LLM 常见错误：if 顺序写反（VIP 判在沉睡前）、边界 ≥/≤ 混淆。

## 设计反哺

多规则优先级判定是高频模式——契语应有"规则表"写法（按序匹配、首条生效）。
