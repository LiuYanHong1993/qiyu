# T14 · 排班冲突检查

- 难度：L2 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV
- 场景：店长每周检查排班表，人工核对冲突费时易漏。

## 标准化提示词（两组通用）

> 读 `shifts.csv`（`姓名,日期,班次[早/晚]`）；输出 `violations.csv`：① 同人同日出现 ≥ 2 条 → 类型=`双班`，日期=该日；② 同人连续 ≥ 7 个自然日有班 → 类型=`连班`，日期=连续段首日。字段 `类型,姓名,日期,说明`；按类型、姓名、日期排序。

## 输入

构造数据：2 处双班、1 段 8 天连班（跨月）、若干正常排班干扰。

## 验收契约（自动断言）

1. 已知答案集全部检出（2 双班 + 1 连班）
2. 零误报（清单每条都在答案集内）
3. 连班段首日正确（跨月样例）
4. 排序正确

## Python 基线备注

LLM 常见错误：连续日判断跨月出错、未按（姓名,日期）排序导致漏检、双班与连班重复报告。

## 设计反哺

分组 + 窗口规则是高频模式——语法设计输入：契语如何让"分组内规则"写得短且无歧义。
