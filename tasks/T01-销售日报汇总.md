# T01 · 销售日报汇总

- 难度：L1 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV
- 场景：运营每天把各区域销售明细导出成 CSV，需要按区域汇总成一张日报。目前人肉复制粘贴约 20 分钟。

## 标准化提示词（两组通用）

> 读取 `~/销售明细/` 下所有 CSV，按区域汇总订单数、数量、金额，输出到 `~/日报/日报.csv`，表头为 `区域,订单数,数量,金额`，按区域名称升序排列。

## 输入

`~/销售明细/` 下多个文件，字段固定：

```csv
日期,区域,城市,产品,数量,金额
2024-06-01,华东,上海,Pro版,3,8700.00
```

## 输出

`~/日报/日报.csv`：

```csv
区域,订单数,数量,金额
华北,4,12,41000.00
华东,12,45,132000.00
```

## 验收契约（自动断言）

1. 输出文件存在、表头一致；区域全集与输入一致（无遗漏、无多出）
2. 每区域三列 = 输入按区域求和（金额容差 < 0.01）
3. 排序符合提示词规定
4. 全程未触发能力清单之外的文件/网络访问

## Python 基线备注

pandas groupby 约 10 行。LLM 常见错误：把合计行计入汇总、GBK/UTF-8 编码混杂、金额含千分位逗号。

## 设计反哺

"按列汇总"应是一等表格算子（`汇总 表 按 列 {}`），让模型没有自由发挥的空间。
