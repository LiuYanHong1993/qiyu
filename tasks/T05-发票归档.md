# T05 · 发票归档

- 难度：L2 ｜ 能力：`fs.read`、`fs.move` ｜ 数据形态：文件系统
- 场景：下载目录里堆着发票 PDF，命名不统一，要按 年-月/供应商 归档。

## 标准化提示词（两组通用）

> 将 `~/下载/`（**含子目录**）中形如 `供应商_日期_金额.pdf` 的文件（日期可能为 `20240601` 或 `2024-06-01` 两种格式）移动到 `~/归档/{年}-{月两位}/{供应商}/`；其他文件不动。目标目录有同名文件时重命名为 `原名_2.pdf`。输出 `~/归档/archive_log.csv`（字段：`原路径,新路径`）。

## 输入

示例文件名：`顺丰_20240601_128.5.pdf`、`德邦_2024-06-02_96.00.pdf`；另有一个干扰文件 `readme.txt`，以及一对同月同供应商同名发票（触发冲突规则）。

## 验收契约（自动断言）

1. 所有匹配文件完成移动（源路径不存在、目标路径存在、内容一致）
2. 归档层级正确（月两位、供应商目录）
3. 干扰文件未被移动；同名冲突按 `_2` 规则
4. archive_log.csv 与实际文件变动一一对应

## Python 基线备注

LLM 常见错误：copy 当 move（源文件仍在）、日期歧义、路径拼接反斜杠。

## 设计反哺

move 是不可逆写操作：契语应要求显式声明，且运行时默认"先复制后删 + 日志"以可回滚。
