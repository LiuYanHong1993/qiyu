# T06 · 报销对账

- 难度：L2 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV × 2
- 场景：财务把报销申请与银行流水核对，人肉 Excel VLOOKUP 半天。

## 标准化提示词（两组通用）

> `expense.csv` 与 `bank.csv` 匹配：键 = 金额精确到分 且 日期相差 ≤ 1 天；一笔流水最多核销一张报销单（一对一）；候选多个时取日期最近的，仍平局取 expense 行号小的。输出 `unmatched_expense.csv` 与 `unmatched_bank.csv`（字段同原表，另加 `原因` 列：`无匹配流水` / `已被核销` / `无匹配报销`）。

## 输入

构造数据含：同金额多笔报销、跨日到账（+1 天）、重复金额流水。

## 验收契约（自动断言）

1. 配对数 ×2 + 两侧未匹配数 = 两表总行数（守恒）
2. 每笔流水至多被使用一次（一对一）
3. "日期就近"平局规则被遵守（构造平局样例）
4. 原因列语义正确

## Python 基线备注

LLM 常见错误：贪心顺序导致误配、写成多对多匹配、守恒关系被破坏。

## 设计反哺

"一对一匹配"是影子 IT 高频复合算子，应进标准库（如 `配对 A B 键=… 容差=…`），而非让模型每次手写贪心。
