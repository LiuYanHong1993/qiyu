# T09 · 销售漏斗统计

- 难度：L2 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：JSON → JSON
- 场景：CRM 每周导出 JSON，运营需要漏斗数据给看板消费。

## 标准化提示词（两组通用）

> 读 `leads.json`（数组，元素：`{客户,阶段,金额}`；阶段枚举按序：线索→意向→方案→成交）；输出 `funnel.json`：`{"阶段":[{"阶段","客户数","金额合计","转化率"}]}`；转化率 = 该阶段客户数 ÷ 线索阶段客户数，保留 2 位小数；阶段按枚举顺序输出，数据中缺失的阶段也要输出（0,0,0.00）。

## 验收契约（自动断言）

1. JSON 通过 schema 校验（字段名、结构精确）
2. 各阶段计数与金额与重算一致
3. 转化率分母 = 线索阶段客户数
4. 枚举顺序正确、缺失阶段补全

## Python 基线备注

LLM 常见错误：枚举顺序按出现次数排、缺失阶段遗漏、分母取错。

## 设计反哺

枚举类型应保序，固定顺序输出应是类型系统的一部分。
