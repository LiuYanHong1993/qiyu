# T19 · 邮件附件归档

- 难度：L4 ｜ 能力：`mail.fetch`（mock）、`fs.write` ｜ 数据形态：邮件 + 文件
- 场景：助理每天从邮箱里把对账单附件存档登记，容易漏、重名覆盖。

## 标准化提示词（两组通用）

> 读 mock 收件箱 `inbox.json`（数组：`{发件人,主题,日期,附件:[{文件名,内容}]}`）；处理主题**含**"对账单"的邮件：附件保存到 `~/归档/{发件人域名}/{文件名}`；目标已有同名文件时以邮件日期追加 `_HHmmss`；输出 `register.csv`（`发件人,主题,保存路径`）。其他邮件一律不动。

## 输入

mock 收件箱 6 封：3 封对账单（其中 2 封同发件人、附件同名）、2 封无关邮件、1 封主题只含"对账"（不含"对账单"）的干扰。

## 验收契约（自动断言）

1. 只处理主题含"对账单"的邮件（干扰件零文件产生）
2. 重名冲突规则生效（时间戳来自**邮件日期**而非系统时间）
3. register.csv 与实际文件一一对应
4. 保存目录仅限归档能力清单内

## Python 基线备注

LLM 常见错误：用系统时间做时间戳（不可复现）、主题匹配边界（含 vs 等于）、重名覆盖丢文件。

## 设计反哺

收件也是能力（要过能力卡）；时间来源必须是数据字段——复现性原则的又一例。
