# T02 · 客户去重合并

- 难度：L2 ｜ 能力：`fs.read`、`fs.write` ｜ 数据形态：CSV × 2
- 场景：两个渠道导出的客户表要合并成主数据表。手机号是主键；同号不同名的要挑出来人工复核。

## 标准化提示词（两组通用）

> 合并 `crm_a.csv` 与 `crm_b.csv`：手机号先归一化（去掉 `+86`、空格、横线，只留 11 位数字）再作为主键；同手机号保留非空字段更多的一条（仍平局取 a 表）；同手机号但客户名不同的行写入 `conflicts.csv`（字段：`手机号,crm_a客户名,crm_b客户名`）。输出 `customers.csv`，字段：`手机号,客户名,公司,邮箱`。

## 输入

```csv
crm_a.csv
手机号,客户名,公司,邮箱
+86 138-0013-8000,张三,示例科技,zhang@ex.com
```

```csv
crm_b.csv
手机号,客户名,公司,邮箱
13800138000,张三,,zhang2@ex.com
```

## 验收契约（自动断言）

1. customers.csv 手机号唯一；行数 = A 去重后 + B 去重后 − 主键重复数
2. 归一化后跨表匹配（`+86`/横线/空格三种写法都能对上）
3. conflicts.csv 条数 = 检测到的同名冲突数；平局取 a 表
4. 未触发能力清单外访问

## Python 基线备注

LLM 常见错误：忘归一化直接精确匹配、"非空字段更多"实现成字符串长度比较、忽略平局规则。

## 设计反哺

"归一化→主键→合并"管道应可显式声明；字符串清洗函数应进标准库。
