# T04 · 每周销售周报 ⭐ 杀手场景

- 难度：L3 ｜ 能力：`fs.read`、`fs.write`、`mail.send`（仅 manager@company.com） ｜ 数据形态：CSV + 邮件
- 场景：每周五把本周销售汇总成周报，存档并邮件发经理。**这是定位一页纸的演示场景，也是未来演示视频的脚本素材。**

## 标准化提示词（两组通用）

> 读取 `~/销售数据/` 下所有 `本周*.csv`，按区域汇总订单数、数量、金额，输出 `~/周报/销售周报.csv`（表头同 T01）；发送邮件到 manager@company.com，主题 `销售周报（{week}）`，附上周报文件。周编号由参数 `week` 传入（如 `2024-W23`）。

## 输入 / 输出

输入同 T01 格式；邮件用 mock 发信器记录（收件人、主题、附件名），不真实外发。

## 验收契约（自动断言）

1. 周报 CSV 满足 T01 全部契约
2. 邮件恰好 1 封、收件人精确匹配、附件路径正确、主题含 week 参数
3. **试运行模式（dry_run=true）下：无邮件调用记录，周报文件照常生成** ← 核心差异化断言
4. 未声明能力（其他收件地址、网络等）零触发

## Python 基线备注

SMTP 配置不进评测（mock 替代）。LLM 常见错误：忘带附件、自行加抄送、试运行模式下仍发信。

## 设计反哺

外发动作必须内建幂等键与试运行屏蔽语义；能力卡由编译器从能力声明自动生成。
